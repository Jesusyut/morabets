=== FIX 2: ROBUST JSON PARSING ===

Find the JSON parse block in
select_picks_with_llm() that does:

raw = response.content[0].text.strip()
picks = json.loads(raw)

Replace with:

raw = response.content[0].text.strip()

# Strip markdown fences if present
raw = raw.replace('```json','').replace(
    '```',''
).strip()

# Find the JSON object boundaries
# Handles truncated or extra text
start = raw.find('{')
end = raw.rfind('}')

if start == -1 or end == -1:
    logger.error(
        f"[LLM] No JSON object found "
        f"in response"
    )
    return None

raw = raw[start:end+1]

try:
    picks = json.loads(raw)
except json.JSONDecodeError as e:
    logger.error(
        f"[LLM] JSON parse error: {e}"
    )
    logger.error(
        f"[LLM] Raw snippet: {raw[:200]}"
    )
    return None

=== FIX 3: PRE-FILTER BOARD DATA
BEFORE SENDING TO LLM ===

The LLM keeps ignoring the book rule
because it sees all books in the data.
Filter BEFORE the LLM sees anything.

Find where board props are assembled
in select_picks_with_llm() or
load_full_board().

Add this filter before the prompt
is built:

# Hard filter — DK and FD only
# LLM cannot select what it cannot see
dk_fd = ['draftkings', 'fanduel']

filtered = [
    p for p in board.get('props', [])
    if p.get(
        'bookmaker',
        p.get('book', '')
    ).lower().replace(' ','').replace(
        'draftkings','draftkings'
    ) in ['draftkings','fanduel']
    and p.get('odds', 0) > -220
    and p.get('odds', 0) != 0
]

logger.info(
    f"[FILTER] {len(board.get('props',[]))} "
    f"props → {len(filtered)} after "
    f"DK/FD and -220 filter"
)

# Replace board props with filtered
board_filtered = dict(board)
board_filtered['props'] = filtered

# Use board_filtered when building
# the prompt — not the original board
