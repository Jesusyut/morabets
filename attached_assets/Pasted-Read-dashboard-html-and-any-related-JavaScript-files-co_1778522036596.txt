=== CHANGE 3: ADD PRIZEPICKS EV
CALCULATION TO EACH CARD ===

PrizePicks pays fixed regardless of
the sportsbook odds. A pick at 65%
true probability against a 50% implied
PrizePicks line is a +30% edge.

Formula:
prizepicks_edge = (no_vig_prob - 0.50) * 100

If no_vig_prob = 0.652:
edge = (0.652 - 0.50) * 100 = +15.2%

Add a small PrizePicks edge indicator
below the best book line on each card.
Only show if edge is positive
(no_vig_prob > 0.50).

Format:
Small pill. Purple background #7C3AED.
White text. 11px. Font-weight 600.

Text:
"PP Edge: +15.2%"

Where 15.2 is calculated dynamically
from the card's no_vig_prob field.

This tells users exactly how much
mathematical edge they have against
PrizePicks fixed payout structure
for each prop.
