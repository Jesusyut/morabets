STEP 1 — DIAGNOSE THE FAILURE FIRST
═══════════════════════════════════════

Find the /api/context-edge route in app.py.

Add temporary detailed error logging
to find exactly where it fails.

Find the try/except block in the route.
In the except clause change it to:

except Exception as e:
    import traceback
    tb = traceback.format_exc()
    logger.error(
        f'Context edge full error: {tb}'
    )
    return jsonify({
        'error': str(e),
        'traceback': tb
    }), 500

Deploy this change only.
Then trigger a failure by clicking
"best bets today" in the chat.

Then run this in the Render shell
to see the exact error:

grep "Context edge" /var/log/render/* 2>/dev/null | tail -20

OR check Render logs directly in the
dashboard under your service → Logs.
Filter for "Context edge" or "error".

Report the EXACT error message and
traceback before any other changes.

The most likely causes in order of
probability:

CAUSE A — anthropic package not installed
Check requirements.txt or pyproject.toml
for anthropic. If missing add:
anthropic>=0.25.0
This is the most common cause.

CAUSE B — ANTHROPIC_API_KEY not set
Run in Render shell:
python3 -c "import os; print(os.environ.get('ANTHROPIC_API_KEY', 'NOT SET'))"
If it prints NOT SET the env var is
missing from Render environment variables.

CAUSE C — Cache files not found
Run in Render shell:
ls -la /var/data/*.json
If mlb_props_cache.json does not exist
the board load fails silently or errors.

CAUSE D — load_board_for_context or
format_board_for_claude functions not
defined in the right scope in app.py —
defined inside the route function instead
of at module level, or defined after
the route that calls them.

CAUSE E — The passcode check returns
before reaching Claude — passcode gate
blocking the quick prompt calls because
sessionStorage is not being sent
correctly from the mobile browser.

STEP 2 — AFTER DIAGNOSIS, APPLY FIX
═══════════════════════════════════════

Report the exact error from Step 1.
Then apply only the fix for that cause.

If CAUSE A — anthropic not installed:
Add to requirements.txt:
anthropic>=0.25.0
Redeploy. Done.

If CAUSE B — API key missing:
Go to Render dashboard →
your service → Environment → Add:
Key: ANTHROPIC_API_KEY
Value: [your Anthropic API key]
Save. Redeploy. Done.

If CAUSE C — cache files missing:
The route needs a graceful fallback.
Find load_board_for_context() in app.py.
Confirm it handles missing files with
try/except already. If not add:
try:
    with open(path) as f:
        props = json.load(f)
except FileNotFoundError:
    continue
except Exception as e:
    logger.warning(f'Cache {sport}: {e}')
    continue

If CAUSE D — function scope issue:
Move load_board_for_context() and
format_board_for_claude() to module
level in app.py — above all routes,
not nested inside the route function.

If CAUSE E — passcode not sent from mobile:
Find sendContextMessage() in dashboard.html.
Confirm sessionStorage.getItem('ce_passcode')
is being included in the fetch body.
Add a console.log before the fetch to
verify passcode value on mobile.
Add to the fetch body explicitly:
passcode: sessionStorage.getItem('ce_passcode') || ''

Also check the passcode validation flow
for the quick prompt buttons specifically —
quickPrompt() calls sendContextMessage()
which requires _ceAuthed to be true.
If the user never went through the
passcode gate (session storage empty
on mobile), _ceAuthed is false but the
gate UI may not be shown correctly.

Add this check at the start of
sendContextMessage():

if (!_ceAuthed) {
  document.getElementById(
    'ce-input-area'
  ).style.display = 'none';
  document.getElementById(
    'ce-passcode-gate'
  ).style.display = 'block';
  return;
}
