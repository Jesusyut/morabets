=== TASK 3: META PIXEL — StartTrial EVENT ===

In the <head> of mora_assists_welcome.html
add the existing Meta pixel base code
(same pixel ID as dashboard.html).

Then fire this custom event on page load
to track trial starts for Meta optimization:

<script>
window.addEventListener('load', function() {
  if (typeof fbq !== 'undefined') {
    fbq('track', 'StartTrial', {
      value:    28.99,
      currency: 'USD',
      predicted_ltv: 57.98
    });
    console.log('[META] StartTrial fired');
  }
});
</script>

This is separate from the Lead event
on the email gate. StartTrial fires only
when someone completes the Stripe checkout
and lands on this page.

predicted_ltv is 2 months average
retention × $28.99.
