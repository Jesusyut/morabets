## STEP 3 — ADD PURCHASE EVENT TO SUCCESS PAGE

This is the most important step.

Open the success page template (success.html or equivalent).
Find the location AFTER the base pixel code would load
(either inherited from base.html or already added in step 2).

Add the Purchase event code inside a <script> tag
in the <body> section of the success page —
place it near the bottom of the page, just before </body>:

```html
<!-- Meta Pixel Purchase Event — fires only on successful payment -->
<script>
  fbq('track', 'Purchase', {
    value: 24.99,
    currency: 'USD',
    content_name: 'Mora Bets Monthly Subscription',
    content_type: 'product'
  });
</script>
<!-- End Purchase Event -->
```

CRITICAL: This Purchase event code goes ONLY on the success page.
Do NOT add it to any other page.
It fires once — when the customer lands on /success after paying.
This is what tells Meta "a real $24.99 purchase happened here."

## STEP 4 — ADD LEAD EVENT TO PAYWALL PAGE

On the pricing/paywall page, add a Lead event that fires
when someone clicks the Subscribe button.
This tracks interested users even if they don't complete payment.

Find the Subscribe button on the paywall page.
Add this to the button's click handler in the JavaScript:

```javascript
// Meta Pixel Lead event — fires when Subscribe button is clicked
fbq('track', 'Lead', {
  content_name: 'Mora Bets Subscription Intent',
  value: 24.99,
  currency: 'USD'
});
```

If the button already has an onclick or addEventListener,
add the fbq line BEFORE the redirect or fetch call.

Example of how it should look:

```javascript
document.getElementById('subscribe-btn').addEventListener('click', async () => {
  // Fire Meta Pixel Lead event first
  fbq('track', 'Lead', {
    content_name: 'Mora Bets Subscription Intent',
    value: 24.99,
    currency: 'USD'
  });
  
  // Then proceed with existing checkout logic
  const btn = document.getElementById('subscribe-btn');
  btn.textContent = 'Loading...';
  // ... rest of existing code
});
```
