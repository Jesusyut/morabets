=== FIX 1: ADD PIXEL TO 
mora_assists_sales.html ===

This page has zero pixel code.
The retargeting campaign sends traffic
here. Meta is completely blind.

In mora_assists_sales.html find the 
closing </head> tag.

Add this block immediately before </head>:

<!-- Meta Pixel Code -->
<script>
!function(f,b,e,v,n,t,s)
{if(f.fbq)return;n=f.fbq=function(){n.callMethod?
n.callMethod.apply(n,arguments):n.queue.push(arguments)};
if(!f._fbq)f._fbq=n;n.push=n;n.loaded=!0;n.version='2.0';
n.queue=[];t=b.createElement(e);t.async=!0;
t.src=v;s=b.getElementsByTagName(e)[0];
s.parentNode.insertBefore(t,s)}(window, document,'script',
'https://connect.facebook.net/en_US/fbevents.js');
fbq('init', '1688269505510635');
fbq('track', 'PageView');
fbq('track', 'ViewContent', {
  content_name: 'Mora Assists Sales Page',
  content_type: 'product',
  value: 28.99,
  currency: 'USD'
});
</script>
<noscript>
<img height="1" width="1" style="display:none"
src="https://www.facebook.com/tr?id=1688269505510635&ev=PageView&noscript=1"/>
</noscript>
<!-- End Meta Pixel Code -->

This is the same pixel ID as all other
pages: 1688269505510635
ViewContent with value 28.99 tells Meta
this is a high-intent product page visit.
Meta will optimize retargeting delivery
toward people likely to spend $28.99.


=== FIX 2: ADD InitiateCheckout TO 
MORA ASSISTS POPUP CTA IN dashboard.html ===

Find the Mora Assists popup in dashboard.html.

Find the primary CTA button — the one that
links to the Stripe day pass or subscription.

It looks like one of these:
  href="https://buy.stripe.com/..."
  onclick with a Stripe link
  An <a> tag pointing to Stripe

Add an onclick handler to BOTH
CTA buttons in the popup
(the $9.99 day pass AND $28.99 monthly):

For the $9.99 day pass button:
Add onclick BEFORE the href fires:

onclick="fbq('track', 'InitiateCheckout', {
  value: 9.99,
  currency: 'USD',
  content_name: 'Mora Assists Day Pass',
  num_items: 1
});"

For the $28.99 monthly button:
onclick="fbq('track', 'InitiateCheckout', {
  value: 28.99,
  currency: 'USD',
  content_name: 'Mora Assists Monthly',
  num_items: 1
});"

If the buttons use <a> tags add the
onclick attribute like this:

<a href="https://buy.stripe.com/..."
   onclick="fbq('track', 'InitiateCheckout', {
     value: 9.99,
     currency: 'USD',
     content_name: 'Mora Assists Day Pass',
     num_items: 1
   });"
   target="_blank">
  Get Today's Picks — $9.99
</a>

The onclick fires the pixel event first
then the href opens Stripe.
Both happen. Nothing breaks.
