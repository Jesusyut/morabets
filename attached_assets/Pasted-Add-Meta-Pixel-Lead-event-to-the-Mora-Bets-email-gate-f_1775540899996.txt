Add Meta Pixel Lead event to the Mora Bets 
email gate form. Fire when a user successfully 
submits their email on the gate popup.

DO NOT touch odds fetching, EV engine,
caching, scheduler, affiliate links,
color scheme, or any existing routes
beyond what is listed below.

=== THE EVENT TO FIRE ===

Per Meta Events Manager instructions,
fire this event on INLINE ACTION —
when the gate form is successfully submitted,
not on page load.

The event code:
fbq('track', 'Lead');

With parameters for better optimization:
fbq('track', 'Lead', {
  content_name: 'Mora Bets Free Access',
  content_category: 'Sports Betting Tool',
  value: 14.99,
  currency: 'USD'
});

Value is 14.99 because that is what the
lead would pay after September 1st.
This tells Meta's algorithm the quality
of the lead for optimization.

=== TASK 2: ADD SERVER-SIDE META 
CONVERSIONS API FOR LEAD EVENT ===

Browser pixels get blocked by iOS and
ad blockers. Server-side ensures the
Lead event reaches Meta regardless.

In meta_pixel.py add this function
if it doesn't already exist:

def track_lead(request, 
               customer_email=None,
               event_id=None):
    """
    Fire Lead event server-side via
    Meta Conversions API.
    Matches browser pixel Lead event
    for deduplication.
    """
    user_data = _extract_user_data(request)
    if customer_email:
        user_data['email'] = customer_email

    custom_data = {
        "content_name":     "Mora Bets Free Access",
        "content_category": "Sports Betting Tool",
        "value":            14.99,
        "currency":         "USD"
    }
    return send_event(
        "Lead",
        user_data,
        custom_data,
        event_id
    )

@app.route('/api/gate-signup', methods=['POST'])
def gate_signup():
    try:
        from meta_pixel import (
            track_lead, 
            get_event_id
        )

        data  = request.json or {}
        email = data.get(
            'email', ''
        ).strip().lower()
        name  = data.get('name', '').strip()

        if not email or '@' not in email:
            return jsonify({
                "success": False,
                "error":   "Invalid email"
            }), 400

        # Check if already exists
        existing = _load_emails()
        if email in existing:
            logger.info(
                f"[GATE] Returning: {email}"
            )
            return jsonify({
                "success":  True,
                "existing": True
            })

        # Save email
        _save_email(email, name)

        count = len(_load_emails())
        logger.info(
            f"[GATE] New signup: {email} "
            f"(total: {count})"
        )

        # Generate shared event_id for
        # browser + server deduplication
        event_id = get_event_id()

        # Fire server-side Lead event
        # to Meta Conversions API
        try:
            track_lead(
                request,
                customer_email=email,
                event_id=event_id
            )
            logger.info(
                f"[META] Lead fired for {email}"
            )
        except Exception as e:
            logger.warning(
                f"[META] Lead event failed: {e}"
            )
            # Never block signup for pixel failure

        return jsonify({
            "success":  True,
            "count":    count,
            "event_id": event_id
        })

    except Exception as e:
        logger.error(f"[GATE] Signup error: {e}")
        # Always return success —
        # never block user access
        return jsonify({"success": True})

=== TASK 4: PASS EVENT_ID TO BROWSER 
FOR DEDUPLICATION ===

Meta deduplicates browser and server events
using the event_id field. Both must match
so Meta counts the lead once not twice.

The server now returns event_id in the response.
Update the browser pixel call to use it:

Find the gate form submit handler and update
the success block:

if (data.success) {

  // Use server event_id for deduplication
  // Falls back to random UUID if missing
  const eventId = data.event_id || 
    crypto.randomUUID();

  // ── META PIXEL LEAD EVENT ──────────────
  try {
    if (typeof fbq !== 'undefined') {
      fbq('track', 'Lead', {
        content_name:     'Mora Bets Free Access',
        content_category: 'Sports Betting Tool',
        value:            14.99,
        currency:         'USD'
      }, {
        eventID: eventId  // deduplication key
      });
      console.log(
        '[META] Lead fired, eventID:', eventId
      );
    }
  } catch(e) {
    console.warn('[META] Lead pixel error:', e);
  }
  // ── END META PIXEL ─────────────────────

  localStorage.setItem('mora_access', '1');
  localStorage.setItem('mora_email', email);

  gate.style.transition = 'opacity 0.4s ease';
  gate.style.opacity = '0';
  setTimeout(() => {
    gate.style.display = 'none';
  }, 400);
}

=== CONSTRAINTS ===

  returning users skip it entirely
- Never block gate access if pixel fails
  Pixel is fire-and-forget
- event_id must match between browser
  and server calls for deduplication
- Value parameter is 14.99 — the post-Sept
  subscription price — tells Meta the
  quality of each lead for optimization
- Do not touch TikTok pixel code
- Do not touch any existing Meta 
  PageView or Purchase events
- Do not touch odds fetching, EV engine,
  caching, scheduler, or color scheme
- Do not touch affiliate links
