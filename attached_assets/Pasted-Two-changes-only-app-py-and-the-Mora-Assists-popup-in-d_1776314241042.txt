=== CHANGE 2: HANDLE day_pass 
IN /zapier/new-assists-subscriber 
ROUTE IN app.py ===

Find the /zapier/new-assists-subscriber 
route.

Read the incoming plan field from 
the POST body:

plan = data.get('plan', 'trial')

If plan == 'day_pass':
  Set status = 'day_pass' in CSV
  Set trial_ends_at = end of today ET
    (today at 23:59:59 ET)
  Do NOT block this email even if 
  they already have an expired trial
  Day pass is always allowed — 
  it is a fresh purchase each time

If plan != 'day_pass':
  Existing trial abuse check applies
  (check if email already has 
  active/trial status, block if so)

Add this helper at the top of the route:

from datetime import datetime, timedelta
import pytz

def get_day_pass_expiry():
    et = pytz.timezone('America/New_York')
    now = datetime.now(et)
    end_of_day = now.replace(
        hour=23, minute=59, 
        second=59, microsecond=0
    )
    return end_of_day.isoformat()

When saving day_pass subscriber to CSV:
  status = 'day_pass'
  trial_ends_at = get_day_pass_expiry()

Update load_active_subscribers() in 
mora_assists.py to include 'day_pass' 
as a valid active status:

Find:
if row.get('status','') in ['active','trial']:

Replace with:
if row.get('status','') in [
    'active', 'trial', 'day_pass'
]:

This means day pass buyers get 
today's picks in the daily send.
Tomorrow their status is still 
'day_pass' but trial_ends_at has 
passed so they are automatically 
excluded from sends.

Extend this same check to day_pass:

if status in ['trial', 'day_pass']:
    trial_end_str = row.get(
        'trial_ends_at', ''
    )
    if trial_end_str:
        try:
            trial_end = datetime.fromisoformat(
                trial_end_str[:19]
            )
            if datetime.utcnow() > trial_end:
                row['status'] = 'expired'
                status = 'expired'
                updated = True
        except Exception:
