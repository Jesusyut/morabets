Add a reusable sticky affiliate footer to the Mora Bets site that stays fixed at the bottom of the screen on both desktop and mobile.

Goal:
Use 3 pre-approved Bovada footer banner creatives and rotate them every 20 seconds while preserving my affiliate tracking on every click.

Requirements:
- Build it as a reusable component named StickyAffiliateFooter if the app uses React
- If the site is plain HTML/JS, add the HTML, CSS, and JavaScript cleanly and modularly
- Keep the footer slim and professional
- On desktop keep it around 50px tall
- On mobile allow it to be slightly taller but still compact
- Keep it visually clean and trustworthy
- Do not block important forms, buttons, chat widgets, or navigation
- Add bottom page padding only while the footer is visible so page content is not covered
- Include a dismiss X button on the right
- Save dismissed state in localStorage for the current browser so the footer stays hidden after dismissal
- Rotate between 3 affiliate banners every 20 seconds
- Pause rotation on hover for desktop
- Fade smoothly between banners
- Open clicks in a new tab using target="_blank" and rel="noopener noreferrer sponsored"
- Make the entire banner area clickable, not just a tiny button
- Keep image proportions clean without distortion
- Make it fully responsive
- Prevent layout shift or flicker on page load

Implementation details:
- Put all banner data in one config array at the top of the component/file
- Each banner object should contain:
  - id
  - imageSrc
  - alt
  - href
  - ariaLabel
- Use my tracked affiliate click URLs exactly as provided
- Do not replace or rewrite the affiliate URLs
- Do not use raw Bovada links unless they are the exact tracked affiliate URLs from the network
- If a banner image fails to load, gracefully skip to the next one
- Keep the code production clean and easy to edit
